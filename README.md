# LED Mask (Sound Reactive)

自分の声に反応して鮮やかに光る、サイバーパンクなLEDマスク用のArduinoプログラムです。
周囲の雑音（クラブの音楽や環境音）を学習して無視し、自分自身の声にだけ反応する「スマート・ノイズフィルター」を搭載しています。

## ✨ 主な機能 (Features)

- **動的ノイズキャンセリング (Auto Noise Gate)**
  周囲の環境音をリアルタイムに学習してベースラインを自動調整。うるさい場所でも自分の声にだけ反応します。
- **音の長さフィルター (Duration Filter)**
  一瞬の物音（マスクに手が当たった音など）を無視し、人間の声特有の「連続した音」のみを判定する疑似AIフィルターを搭載。
- **ディープカラー・プログレッション (HSV Color)**
  ランダムなRGBによる白飛びを防ぎ、HSV制御で常に鮮やかな原色を発色。声に連続して反応するごとに、色がだんだんと濃く（ディープに）変化していきます。
- **省電力＆安定駆動**
  輝度を適切に調整し、モバイルバッテリーからのUSB給電で安定して動作します。

## 🛠 必要なハードウェア (Hardware Requirements)

- **Arduino Nano** (互換機可)
- **フルカラーLEDテープ** (WS2812B / NeoPixelなど)
- **アナログ音センサーモジュール** (マイク)
- **USBモバイルバッテリー** (給電用・推奨)

## 🔌 配線 (Wiring)

| パーツ | Arduino Nano |
| --- | --- |
| LEDテープ DIN | **D2** ピン |
| LEDテープ VCC | **5V** ピン |
| LEDテープ GND | **GND** ピン |
| 音センサー OUT | **A0** ピン |
| 音センサー VCC | **5V** ピン |
| 音センサー GND | **GND** ピン |

> **💡 実装時のポイント**
> 音センサー（マイク）は、**マスクの内側（口の横など）**に配置してください。マスクの布が外の音を遮断し、強力な物理的ノイズキャンセリング効果を発揮します！

## 🚀 使い方 (How to Use)

1. Arduino IDEを開き、`ledmask/ledmask.ino` を開きます。
2. ライブラリマネージャーから `Adafruit NeoPixel` がインストールされていることを確認します。
3. コード内の `#define NUM_LEDS 20` を、実際に使用するLEDの合計数に変更します。
4. Arduinoに書き込みます。
